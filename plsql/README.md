# Exercise 01 - Control Structures

## Scenario 1
Apply a 1% discount to loan interest rates for customers above 60 years old.

## Scenario 2
Promote customers to VIP if their account balance exceeds 10,000.

## Scenario 3
Display reminder messages for customers whose loan due date falls within the next 30 days.

## Concepts Used

- PL/SQL Block
- FOR LOOP
- IF Statement
- UPDATE Statement
- JOIN
- DBMS_OUTPUT.PUT_LINE
- COMMIT
- Date Functions (SYSDATE)
